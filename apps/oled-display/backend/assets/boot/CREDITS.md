# Boot icon credit

`hardware-icon.png` is a rasterized copy of the router/hardware pictogram
already used elsewhere in meshpoint's own dashboard sidebar (next to
"Hardware" under the Radio group, `frontend/index.html`) — a user-supplied
SVG originally sourced from [svgrepo.com](https://www.svgrepo.com/svg/521814/router).
Per that file's own comment, the exact per-icon license on svgrepo
couldn't be confirmed (the site blocks automated license lookups); it's a
generic router pictogram, not a brand mark. Rasterized here at 48x48 via
`rsvg-convert` for use on the OLED boot/restart screen.
